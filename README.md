# 一箭又一箭（One Arrow After Another）

> 软件工程课程第二次个人作业 —— 基于 Python + Pygame 的点击式箭头解谜小游戏

## 游戏简介

"一箭又一箭"是一类点击式箭头解谜游戏。棋盘中分布着若干方向为上 / 下 / 左 / 右的箭头，玩家需要观察箭头之间的阻挡关系，按照正确顺序点击箭头，使所有箭头依次飞出棋盘。

- 若点击的箭头沿指向方向到棋盘边界之间**没有其他箭头**，箭头飞出棋盘并被消除；
- 若路径上存在其他箭头，箭头被挡住，不能消除，会**左右晃动并变红**提示，同时消耗 1 次失误；
- 失误次数耗尽则本关失败，可重新开始；清空本关全部箭头则进入下一关。

## 开发环境

- Python 3.8+
- Pygame 2.x

## 安装与运行

```bash
# 1. 安装依赖
pip install pygame

# 2. 运行游戏
python one_arrow_game.py
```

## 操作说明

| 操作 | 说明 |
|---|---|
| 鼠标左键点击 | 选中 / 射出箭头 |
| 点击「重新开始」按钮 | 恢复当前关初始布局与失误次数 |
| 开始界面点击「开始游戏」 | 进入第 1 关 |
| 通关 / 失败后点击任意处 | 进入下一关 / 重玩本关 |

## 界面

- **开始界面**：游戏标题 + 开始按钮
- **游戏界面**：顶部显示当前关卡、剩余箭头数、剩余失误数、重新开始按钮；中部为棋盘
- **结果界面**：通关提示（进入下一关）/ 失败提示（重玩本关）/ 全部通关提示

## 实现要点

- **棋盘表示**：二维列表，单元格为 `None`（空格）或 `'U'/'D'/'L'/'R'`（箭头方向）。
- **方向向量**：`U=(-1,0)`、`D=(1,0)`、`L=(0,-1)`、`R=(0,1)`。
- **路径检测**：从被点箭头沿方向向量逐步前进，只要在越界前遇到非空单元格即判定"被阻挡"，否则可飞出。
- **动画**：可飞箭头沿方向平移 0.4 秒后消失；被挡箭头用正弦函数左右位移 + 变红做 0.4 秒晃动反馈。
- **关卡**：3 个手工设计且经暴力搜索验证可通关的关卡。
